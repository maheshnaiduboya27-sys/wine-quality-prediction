# Wine Quality Prediction

## Project Overview

This project uses Machine Learning to predict wine quality based on
different physicochemical properties of wine.

## Problem Statement

The objective is to build a machine learning model that can predict
wine quality using features such as acidity, sugar, alcohol, sulphates,
and other chemical properties.

## Dataset

The dataset contains wine quality information and physicochemical
features.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Train-Test Split
6. Feature Scaling
7. Model Training
8. Hyperparameter Tuning
9. Model Evaluation
10. Streamlit Deployment

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- KNN
- SVM

## Model Evaluation

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Application

A Streamlit application was created to allow users to enter wine
properties and receive a predicted wine quality.

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the Streamlit application:

streamlit run app/app.py
